# Release eBisnis v1.26.0

## Stok Opname: Unduh Excel, Unggah Excel, Cetak PDF

- Layar Stok Opname kini punya 3 tombol baru: **Unduh Excel** (seluruh riwayat opname toko, bukan cuma hari ini), **Unggah Excel** (isi hasil hitung fisik dari file Excel -- tiap baris jadi catatan baru, tidak menimpa data lama), dan **Cetak PDF** (riwayat hari ini).
- Tombol-tombol ini hanya tampil untuk admin/manager atau supervisor toko, sama seperti hak akses mencatat Stok Opname yang sudah ada.

> Catatan: fitur ini butuh restart server AIS untuk aktif penuh di sisi server.

## Instalasi
- **Windows**: unduh `eBisnis-Setup-1.26.0.exe` (atau `Al-Bahjah-POS-Setup-1.26.0.exe` untuk varian bermerek Al-Bahjah) dan jalankan.
- **Android**: unduh `eBisnis-1.26.0.apk` dan instal (aktifkan "izinkan dari sumber tidak dikenal" bila diminta).
